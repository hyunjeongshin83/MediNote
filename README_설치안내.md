# MediNote 배포 & 앱 설치 안내

이 폴더의 파일들을 **같은 폴더(같은 도메인)** 에 그대로 올리면 됩니다. 링크 하나로 열리고, 홈 화면에 앱으로 설치됩니다.

## 1) 웹에 올리기 (무료 · GitHub Pages 예)
1. GitHub 새 저장소 → 이 폴더 파일 전체 업로드
2. Settings → Pages → Branch: main / (root) 저장
3. 몇 분 뒤 `https://<아이디>.github.io/<저장소>/MediNote_app.html` 로 열립니다
   - HTTPS여야 설치·위치·클립보드·QR가 모두 작동합니다.

## 2) 앱 설치(다운로드) 방법
- **안드로이드 Chrome**: 앱을 열면 아래에 **‘MediNote 앱 설치’** 배너가 뜹니다 → [설치].
  (배너가 안 보이면 브라우저 메뉴 ⋮ → ‘앱 설치’ / ‘홈 화면에 추가’)
- **아이폰 Safari**: 아래 **공유** → **‘홈 화면에 추가’**. (설치 배너를 누르면 안내가 나옵니다.)
- 설치하면 홈 화면 아이콘으로 앱처럼 실행되고, 오프라인에서도 기본 화면이 열립니다(서비스워커 캐시).

## 3) 클라우드(선택) 켜기
- 기록은 기본으로 기기에 저장되고, Supabase `hub_state` 테이블을 한 번만 만들면 클라우드에도 저장됩니다.
- 신고·공유 페이지 상단 배지로 **클라우드 ON/대기**를 바로 확인할 수 있습니다.
- 표 생성 SQL·구글 로그인·웹푸시·공공데이터 키 연결은 함께 넣어둔 가이드(.md) 참고.

## 포함 파일
- `MediNote_app.html` — 메인 앱(복약·예방접종). 증상 기록·신고·공유·설치 포함
- `증상신고_공유.html` — 증상 신고·공유(앱에서 임베드로 열림)
- `오늘증상기록.html` — 증상 기록 단독 페이지
- `manifest.webmanifest`, `신고공유.webmanifest` — 설치용 매니페스트
- `MediNote.sw.js` — 서비스워커(오프라인·설치)
- `icon-*.png`, `apple-touch-icon.png`, `favicon-32.png` — 앱 아이콘
- `예방접종_데이터API.html`(+매니페스트) — 국내·국제 접종 실데이터
- `seed_cards.html` — 예시 안내카드 DB 채우기
- `공공데이터_API키_발급연동_가이드.md`, `웹푸시_알림_설정가이드.md` — 연결 가이드

> 로고 PNG(meditlogo*.png)를 같은 폴더에 함께 올리면 헤더에 로고가 표시됩니다(없어도 앱은 정상 작동).

MediNote · 정보 제공·상담 연결까지만, 판정·처방은 하지 않습니다. 처방은 의사, 조제·상담은 약사.
