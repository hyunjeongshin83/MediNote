# 웰다(Welda) 앱 살펴보기 — UI · 진행 형태 · 센싱 후 데이터 관리 (2026-10-15)

대표님 요청: 웰다의 **UI · 진행 형태 · 하드웨어 센싱 후 데이터 관리**를 보고, 우리 앱에 줄 시사점을
**데이터를 조합해 자기 의견**으로 정리.
`www.welda.co.kr/program/` 은 이 환경(프록시)에서 열리지 않았습니다. 아래는 **언론 보도 검색**으로
확인한 것이고, 앱 화면(UI)은 직접 보지 못했습니다. 화면 캡처를 주시면 6절을 채웁니다.

## 1. 사실 (출처가 있는 것만)

| 항목 | 내용 | 출처 |
|---|---|---|
| 운영 | 대웅제약 계열 엠서클, 2024-10 출시. 이름은 「웰 다이어트」 | 신아일보 · 이코노믹리뷰 · 청년의사 · 데일리팜 |
| 센싱 | 연속혈당측정기(CGM)와 연동해 실시간 혈당 표시, 혈당에 영향을 주는 음식 파악 | 같음 |
| 센서 없이 | CGM 2주 착용 뒤에는 센서 없이도 음식별 혈당 반응을 예측하는 기능 | 같음 |
| 기록 | 「푸드 카메라」 — 음식 사진 촬영만으로 AI가 식사 자동 기록 | 같음 |
| 진행 | 전문가 1:1 코칭, 주기적 상태 점검, 혈당 스파이크 줄이는 레시피 · 데일리 미션 | 같음 |
| 효과 주장 | 약 2,000명이 3개월 체험, 허리둘레 평균 1인치(최대 7.7인치) 감소 — **회사 자체 조사**, 대학과 효과성 검증 연구 진행 중이라고 함 | 같음 |

**확인하지 못한 것**: 프로그램 기간 · 가격 · UI 화면 구성 · 앱스토어 리뷰 · 의료기기 인허가 여부 ·
데이터가 서버에 어떻게 저장되는지. 이 줄들은 **추측으로 채우지 않았습니다.**

## 2. 구조로 읽으면 (사실에서 바로 따라오는 것만)

```
센싱(CGM)  →  기록(사진 AI)  →  예측(2024 출시 보도: 센서 없이도)  →  코칭(전문가 1:1 + 주기 점검)  →  습관(미션)
   기기          입력 부담↓         (현행 흐름은 FAQ 확인 필요)         동기 유지                      반복
```

- **2024년 출시 보도 기준으로는 센서 착용 2주 뒤 센서 없이 예측하는 흐름**이었습니다. 다만 이것은 출시 당시
  설명이고, **현재 공식 FAQ는 첫 한 달 연속 착용을 권하고 필요하면 계속 쓸 수 있다고 한다**는 지적이 검토에서
  나왔습니다(`www.welda.co.kr/faq/` — 이 환경에서는 열리지 않아 직접 확인하지 못했습니다). 그래서
  「하드웨어 의존을 줄이는 설계」라는 결론은 **내리지 않습니다.** 현재 흐름은 공식 페이지 확인이 필요합니다.
- **입력 부담을 사진으로 없앱니다.** 고령 사용자에게는 글자 입력보다 사진이 쉽다는 점은 우리 앱에도 해당합니다.
- **코칭은 전문가 1:1이 있다는 것까지가 확인된 사실입니다.** 같은 보도는 AI가 혈당 반응을 예측하고 맞춤
  솔루션을 준다고도 하고, 현재 프로그램 페이지는 AI 피드백 · 개인화 AI 코칭을 내세운다는 지적이 있었습니다.
  따라서 「사람이 모든 결과를 해석한다 / 앱은 판정하지 않는다」는 **추정하지 않으며, 규제 구분의 근거로도
  쓰지 않습니다.**

## 3. 우리 앱에 대한 의견 (제안 — 결정은 대표님)

| 웰다에서 | 우리에게 | 의견 | 막는 것 |
|---|---|---|---|
| CGM 연동 | 안드로이드 Health Connect · iOS HealthKit 이 이미 있음(걸음 · 수면 · 심박) | 센서를 새로 사지 말고 **이미 읽는 값**으로 시작. 지금은 화면 표시만 하고 저장하지 않음 | 저장하려면 건강 데이터 저장 위치 결정(동의 · 법적 검토) |
| 센서 → 예측 | 금연노트 · 금주노트는 센서가 없음 | 무리하게 예측을 흉내 내지 않기. 「기록 → 내 패턴 보기」(이미 있음)가 우리 수준 | 예측 문구는 「진단 · 위험 알람」 판정에 닿음(CLAUDE.md §2) | <!-- phrase-ok: 쓰지 말라는 인용 -->
| 사진 AI | 없음 | 약 봉투 · 처방전 사진으로 복약 일정 채우기가 가장 가까운 후보 | 사진이 서버(AI)로 나감 → 국외이전 동의 · 처리방침 먼저 |
| 1:1 코칭 | 금주노트의 「약사 · 상담자와 함께 보기」 | 우리는 **사람에게 연결**하는 쪽으로 간다(웰다의 규제 처리와 비교한 결론은 아님) | 상담 주체 확인(`LEGAL-REVIEW-COUNSELING.md`) |
| 데일리 미션 | 접종 시기 알림 · 복약 알림 | 미션은 **마신 날을 실패로 쓰지 않는** 형태만(금주노트 규칙 §2) | 문구 변경은 확인 필요 |

## 4. 경고 (웰다를 따라 하면 걸리는 것)

- 「혈당 예측」 · 「실시간 혈당」 은 **의료기기 영역**입니다. 웰다는 계열사가 제약사이고 효과성 연구를
  대학과 진행한다고 하므로 인허가 경로가 있을 수 있으나 **확인하지 못했습니다**. 우리가 같은 표현을 쓰면
  판정이 뒤집힙니다(식약처는 표시된 사용목적으로 가름 — `docs/STORE-LISTING.md`).
- 「허리둘레 7.7인치 감소」 같은 **효과 수치는 회사 자체 조사**입니다. 우리 홍보문구에 옮기지 마세요.
